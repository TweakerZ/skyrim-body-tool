Body Tool 0.1.2 moves the app out of the launcher and into the Skyrim Mod Loader plugin list.

**What's new**

- Renamed to Body Tool and moved to the `com.skyrimandroid.bodytool` package.
- No launcher icon. Skyrim Mod Loader starts the app from its plugin section, so the drawer stays clear of the Skyrim tools.
- Icons, preset builds, batch builds, per-file conflict handling and mod zip output are unchanged.

**Install**

Download `BodyTool-0.1.2.apk` and install it. Android 7.0 (API 24) or newer, arm64. The package id changed, so uninstall the old `com.bodyslide.android` build first.
