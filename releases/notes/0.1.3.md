Body Tool 0.1.3 lets every conflict batch pick its winners and moves the dialogs to the suite theme.

**What's new**

- The conflict dialog offers two paths on any batch size: **Continue build** keeps the first set winning each file, **Choose winners** lists each conflicting file so you can pick the outfit that builds it.
- Large batches use a lazy list, so the conflict dialog opens instantly with hundreds of conflicts.
- Confirm, log and path dialogs use the same Material 3 style as the rest of the suite instead of the grey platform dialog.
- The settings sheet clears the status bar and navigation bar insets.

**Install**

Download `BodyTool-0.1.3.apk` and install it over the existing app. Android 7.0 (API 24) or newer, arm64.
